## 维护

这是一个无需构建的静态网站，使用 HTML、CSS 和 JavaScript。GitHub Pages 从 `main` 分支的根目录发布。

- `index.html`：主页内容。
- `styles.css`：桌面、移动端与打印样式。
- `script.js`：复制邮箱与打印功能。

修改这些文件并提交到 `main` 后，GitHub Pages 会自动更新。也可以先在本地通过静态 HTTP 服务预览。
